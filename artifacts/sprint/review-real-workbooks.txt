Workbooks written by spreadsheet programs, read with the service's reader and compared with an
independent reading (openpyxl in its ordinary in-memory mode).
The files: the 36 .xlsx files in pandas/tests/io/data/excel of github.com/pandas-dev/pandas at commit
264b9d8f97 (2026-11-18T19:00:24Z), written by Microsoft Excel 12 to 16 (Windows and Macintosh) and
LibreOffice 4.2 to 7.3. They are test data of that project, not procurement data, and are not part
of this repository. Run once, on the final code, on the build machine. Command, from services/api:
  uv run python ../../scripts/compare_workbooks.py <directory with the files>
Each line: file, the program named in the file's properties, and for each worksheet either
'identical' with the number of data rows, or the reason the reader refused it. EMPTY_FILE,
MISSING_HEADER and DUPLICATE_HEADER are refusals of a layout the reader does not accept (a title
above the header, index columns without a name, a repeated header); they are not differences.
The output is unchanged.
