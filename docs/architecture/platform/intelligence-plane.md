# Intelligence Plane (Draft)

**Status**: Draft
**Scope**: Post-MVP (Phase 4)
**Not active implementation guidance**

---

## 1. What This Plane Is Not

It does **not** replace the deterministic Operational Plane. It
**augments** it — produces candidates, calibrates confidence, learns
rankings — but the operator always sees deterministic math in the
Morning Brief.

No model ships until it beats a deterministic baseline offline.

---

## 2. Five Engines

A monolithic "AI module" rots. The plane is split into five engines,
each with a distinct job.

### Engine 1 — Prediction

| Concern | Method |
| --- | --- |
| Risk prediction | GNN on Operational Graph |
| Demand forecast | time series |
| Failure probability | classifier on World Model history |

**Output**: probabilities stamped on nodes/edges in the World Model.

### Engine 2 — Optimization

| Concern | Method |
| --- | --- |
| Policy learning | RL over simulated world states |
| Action search | tree search on candidate mitigations |
| Allocation | convex / MILP for inventory rebalancing |

**Output**: candidate action plans ranked by expected value.

### Engine 3 — Reasoning

| Concern | Method |
| --- | --- |
| Natural language | LLM (tool-use, structured output) |
| Internal chain-of-thought | hidden, audited |
| Structured planning | decompose mission → task graph |

**Output**: explanations, plan drafts, natural-language summaries. The
brief's math is never generated by an LLM.

### Engine 4 — Simulation

| Concern | Method |
| --- | --- |
| Synthetic worlds | Monte Carlo over World Model forks |
| Scenario expansion | stress test, stress shrink |
| Digital twin | replay historical incident under hypothetical choices |

**Output**: counterfactual outcomes. This is what feeds the Memory
Plane's `Counterfactual` and `Confidence Error` fields.

### Engine 5 — Evaluation

| Concern | Method |
| --- | --- |
| Benchmarking | backtest suite runs after each model change |
| Calibration | reliability diagrams, Brier score |
| Safety | adversarial probes, drift detection |
| Regression | comparison to deterministic baseline |

**Output**: a pass/fail gate before any model is promoted from shadow
to shadow-with-display.

---

## 3. Training Substrate

The plane trains from the Memory Plane only. Prerequisites (all must
hold):

- Decision memory exists.
- Outcomes are logged.
- Historical labels are clean.
- Backtests exist.
- Replay is stable.

Until then, no training runs. Training on guessed labels is forbidden
(architectural principle #10).

---

## 4. Promotion Path

A model moves through these stages:

```
offline experiments
  → shadow inference (no display)
    → shadow with display (operator sees, not used)
      → assisted (operator can override)
        → autonomous (if policy permits)
```

Each gate has an explicit ADR. Each gate has an offline benchmark the
model must beat.

---

## 5. MVP Status

None of these engines exist. The wedge uses pure-functional
deterministic engines in `app/modules/disruption/engines/`. The
Intelligence Plane is a Phase 4 build.
